# Mitwirken

Danke für Feedback und Verbesserungen am Portfolio.

## Änderungen vorschlagen

1. Einen Branch vom aktuellen `main` erstellen.
2. Änderungen klein und nachvollziehbar halten.
3. Vor dem Pull Request `pnpm validate` ausführen.
4. Keine Zugangsdaten, Tokens oder echten `.env`-Dateien committen.
5. Bei UI-Änderungen deutsche und englische Routen sowie mobile Darstellung prüfen.

Pull Requests nach `main` werden automatisch formatiert, gelintet, typgeprüft, getestet, gebaut und sicherheitsgeprüft.

## Sicherheitsprobleme

Bitte Sicherheitsprobleme nicht öffentlich als Issue melden. Die Kontaktmöglichkeit und der erwartete Inhalt stehen in [SECURITY.md](SECURITY.md).
