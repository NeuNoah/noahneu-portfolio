# Sicherheitsmeldungen

Bitte melde vermutete Sicherheitsprobleme nicht öffentlich in einem Issue.

Sende eine kurze Beschreibung an **neu.noah@web.de**. Bitte keine Passwörter,
API-Tokens oder anderen geheimen Zugangsdaten in die Meldung aufnehmen.

Für Änderungen am Projekt gilt:

- Secrets gehören ausschließlich in lokale `.env`-Dateien oder Vercel-Umgebungsvariablen.
- `.env*`-Dateien sind im Repository ausgeschlossen.
- Pull Requests müssen die automatischen Qualitätsprüfungen bestehen.
